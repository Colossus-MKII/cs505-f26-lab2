Single-cycle, 1.779 ns. The path starts at a PC/address flip-flop and ends at the high byte of GPR 9. The mapped gates select the fetched instruction from RAM, use its source-register index to read the GPRs, propagate a carry through the address calculation, then select RAM read data and feed register writeback. This is the load path. The byte-lane sign bits in the final selection are consistent with a sign-extending load. Both instruction fetch and data access fit within this one period.

Multi-cycle, 0.857 ns. Both endpoints are controller-state flip-flops. The selected path runs through instruction decode, the A/B ALU carry chain, the shared bus, and comparison with register A before the FSM chooses its next state. This corresponds to the branch-decision micro-operation (STATE_BRANCH_1 selects target calculation or a new fetch). Static timing can combine shared mux arcs from mutually exclusive control states, so the path does not establish that any single branch dynamically exercises every arc.

Three-stage, 1.112 ns. The registered EX instruction selects rs1 through the register-file and forwarding muxes. A carry chain combines the operand with the instruction immediate, and the redirect mux feeds the PC register. This is the register-indirect jump target calculation, JALR: PC receives (rs1 + immediate) with bit 0 cleared. The register selection and the full target addition lie in one stage.
